# Student Management System 🎓

A **C# Windows Forms** application for managing student records using a database.

## 🚀 Features
- Add, update, delete student records.
- Search for students by name or ID.
- Save and retrieve student data from a textfile.
- v1 contains database functionality

## 🛠️ Technologies Used
- C# (WinForms)
- ADO.NET (SQL Database)
- Microsoft SQL Server / SQLite
